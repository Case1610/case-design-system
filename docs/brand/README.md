## 次に行うこと

新しい制作Issueを立て、このメモを参照する。既に担当が付いたIssueに別エージェントが着手しない。

1. 既存試作を実際に表示して確認する。READMEの評価だけで採否を決めない。
2. 要件に沿った短い設計メモの下書きと視覚的な候補を提示し、本人の反応から一つずつ絞る。白紙の質問票や抽象的な理念の確定を前提に止めない。
3. 候補への本人の発言を、採用・却下・保留の区別とともに記録する。AIの解釈は分けて書く。
4. 中断時に候補のファイル、評価、未決事項、次の一手を更新する。
